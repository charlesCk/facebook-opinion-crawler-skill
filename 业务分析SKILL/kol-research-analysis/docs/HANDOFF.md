# Handoff - KOL Research Analysis

## What This Project Does

Turns private KOL history review into a reusable public-safe analysis framework.

## How To Reuse

1. Keep raw KOL material in a private workspace.
2. Use `references/analysis-framework.md` to structure the review.
3. Use `references/public-safe-template.md` for sanitized summaries.
4. Commit only the method, not raw numbers or private documents.

## Extension Notes

- Add fake examples before adding any real-looking case output.
- Separate market differences such as Hong Kong, Taiwan, and Singapore.
- Always distinguish public-source evidence from internal business data.
